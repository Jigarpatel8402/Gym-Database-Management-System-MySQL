Payment(payment_id, member_id, amount, date)

Database structure designed for performance & integrity

Key SQL Queries

Active members

SELECT name, phone FROM Member WHERE status='Active';

Member with trainer

SELECT Member.name, Trainer.name FROM Member JOIN Trainer ON Member.trainer_id = Trainer.trainer_id;

Progress trend

SELECT member_id, weight, date FROM Progress ORDER BY date;
